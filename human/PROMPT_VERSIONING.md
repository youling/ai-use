# Human Prompt Versioning

## Principle

Prompts used as data generation instruments are part of provenance.

A Deposit is not only produced by a model. It is produced by:

- source conversation;
- model/runtime;
- prompt version;
- transport capability.

## Version Rules

Use semantic versioning (`X.Y.Z`).

- MAJOR: incompatible output or governance changes;
- MINOR: new compatible fields or capabilities;
- PATCH: wording fixes or clarifications without schema change.

Old generated artifacts keep their original prompt version.

Never rewrite history only to make old outputs appear generated by a newer prompt.

## Why

Future evaluation must distinguish:

- Human change;
- model capability change;
- prompt change;
- compression rule change.

Without provenance, these cannot be separated.
