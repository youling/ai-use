# PROBE_AND_VERIFY_PLAYBOOK — 探测与验证作业手册

> 定位：**guidance**，帮助选择诊断路径，不新增权限、协议或统一验收门。授权与事实边界见 [AGENTS.md](../AGENTS.md)，验证政策见 [Constitution §7](../CONSTITUTION.md#7-verification-policy--canonical)。
> 来源：[公开提案 #175](https://github.com/youling/ai-use/issues/175) 汇集的 2026-10-22/23 两轮场景经验；按[原作者更正](https://github.com/youling/ai-use/issues/175#issuecomment-6337780559)与[修订裁决](https://github.com/youling/ai-use/issues/175#issuecomment-6777619152)收敛。源场景的操作限制只约束该场景，不自动成为所有项目的规则。

## 0. 从能回答问题的证据开始

**先清点既有来源，再决定是否新采集；解释零结果前，检查测量路径和比较口径。** 既有来源足以回答问题时直接复用；缺少所需范围、字段或当前性时，再选择获授权的补证路径。这是诊断顺序建议，不承诺固定耗时或某种工具总是更快。

## 1. 路线决策表

| 情形 | 优先检查 | 结论边界 |
| --- | --- | --- |
| 某时间窗没有数据 | 已有导出件、账单、封存响应的结构、时间列、状态与主键范围 | 已读来源为空不等于总体不存在 |
| 得到 0 匹配 | §2 五槽位，必要时用已知答案作正控 | 匹配失败不自动否定业务关系 |
| 需要平台侧计数 | 查询范围、传输依赖、分页终态与现场回执（§6） | 一页或一个页签不自动代表总体 |
| 两个数不一致 | 同一总体、时间窗、状态集合、去重与统计单位 | 先排除口径差，再判断漏数 |
| 保存或发布证据 | 保存目的、接收方与访问边界（§5） | 私域原件保真与公开输出分别处理 |

## 2. 零结果五槽位

可以如实报告“本次查询返回 0”。若要进一步解释原因或断言总体缺失，按该结论检查以下相关槽位；不适用项说明原因，缺证据的推论保留 `UNKNOWN`，不要抹去已经成立的观测。

1. **SCOPE**：数的是哪个总体？明确来源、时间列、时间窗、时区、状态集合、账户范围与统计单位。
2. **CONTROL**：同一读取或匹配路径在已知有答案的输入上是否有效？正控失败时先排查测量器；没有正控或等价有效性证据时，不用零结果证明对象不存在。
3. **NAMESPACE**：标识符在什么范围内唯一，哪些配对有语义依据？同名、同格式不等于同一实体。
4. **COVERAGE**：筛选、分页、导出上限、分片与可见权限是否覆盖所声称的范围？子集行数不能充当总体计数。
5. **VISIBILITY**：来源在什么业务阶段才出现该记录？例如未结算交易可能尚无结算账单行；这需要来源机制及样本支持，不能凭经验代入。

**来源筛选造成的 0、在明确范围内确认缺失、机制可解释的 0** 是不同结论，证据强度也不同。

## 3. 零捕获先检查测量器

- 检查事件是否启用、目标是否正确、观测窗口是否足够、类型或 URL 过滤是否过窄，以及已知正控是否可见。
- 不能确认测量路径有效时，可标记 `CAPTURE_UNKNOWN`、`PARTIAL` 或 `OBSERVATION_INCOMPLETE`；不要声称覆盖完整或“对方没有接口”。这些是证据说明，不是新 Work 状态。
- 源场景曾因事件类型大小写比较错误而零捕获。诊断时检查实际事件结构与过滤条件，不根据空列表猜测平台能力。

## 4. 按实际风险选择验证

验证强度遵循 [Constitution §7](../CONSTITUTION.md#7-verification-policy--canonical) 和当前任务验收，不统一要求两条或三条读取路径，也不据此增加 Verifier 数量。

对会影响关键结论的解析、计数或匹配风险，可选择已知答案样本、来源侧同口径计数、抽样回读，或实现不同的读取路径。交叉读取要比较同一输入和口径；两个工具共享同一错误假设时，结果一致也不能排除该错误。“测试通过”只证明已测范围，不能代替未执行的真实来源验证。

## 5. 原件、公开输出与 secret 分开

| 对象 | 处理原则 |
| --- | --- |
| 已授权 owner 私域中的原始证据 | 按项目数据合同保真保存，保留来源、范围和必要校验值。标识符、金额或原始行不因字段外观而自动成为应删除内容；不要让脱敏产物覆盖唯一原件。 |
| 公开报告或扩大受众的输出 | 按已授权受众选择最少必要信息；可用计数、分布、掩码与受控证据指针支持结论。哈希、路径和指针也要检查是否暴露私域信息，不能仅凭格式标记为 `safe`。 |
| 密码、令牌、Cookie、私钥等 secret | 遵守既有凭据保管与访问规则，不写入公开仓、聊天或普通日志。原件保真不授权导出凭据；确需保留含 secret 的原始材料时，使用项目已授权的受限保存边界。 |

发布前按实际风险检查输出。检测器只报告必要的类别、位置、掩码或长度，不把完整命中值复制到日志；检测命中是审查线索，不自动证明原件应被改写。修正规则误报时保留有针对性的样本验证。未知归属的历史文件先交 owner 判断，不顺手清理。

原始与派生数据、保存期限及用途的分界见 [Durable Data Doctrine](../docs/DURABLE_DATA_DOCTRINE.md)；本文不另设永久保留或“真实数据只能留在本机”的规则。

## 6. 根据依赖选择传输

1. **识别依赖**：账户权限、会话、签名、CSRF、动态参数、时间窗、分页游标与服务端任务状态。
2. **选择受支持路径**：在当前授权和工具允许范围内，采用能满足依赖的 API、HTTP 或页面操作。页面能生成请求不等于可以导出其凭据或离线重放；是否可用页面 SDK、脚本或请求构包，以当前工具及来源访问约束为准。
3. **核对回执**：检查状态、结构、查询边界、行数、去重和分页终态。日期要核对业务时区及左右端点是否包含，不能只看界面显示。

签名是传输依赖，不是授权证明；无签名也不代表请求无副作用。一次成功不能外推到其它账号、路由或时间窗。不得换工具、账号或环境规避访问拒绝；真实故障修复和受支持替代路径仍按当前授权判断。

## 7. 写任务隔离工作区

按 [Agent Interface §1.0](../docs/AGENT_INTERFACE.md#10-common-execution-hygiene) 使用物理隔离的可写工作区，例如独立 worktree 或 clone。不同分支共用同一 working tree 不算隔离，“按路径提交”也不能替代隔离。

只提交受托路径，提交前核对 diff 与暂存范围；不清理、重排或覆盖他人及未知归属的状态。发现共享可写现场时先解决隔离与归属，不靠提交命令掩盖冲突。

## 8. 外部执行体与传输范围

模型、工头或远端工具只接收其任务所需且已获授权的数据。通用合同与合成夹具适合方法验证；需要真实来源时，沿 owner 已授权的接收方、用途和保存边界传输。既有授权足够时继续执行，不因跨设备或换执行体机械重问；委派本身也不扩大数据与 secret 权限。

产出按 §4 验收。留存足以复现的输入/版本指针、按 §5 受众与 secret 边界处理后的必要命令参数、执行结果与 artifact digest；不为追求“完整命令”把 secret 写进回执。留痕格式仍由 [Durable Trace](../30_PROTOCOLS/DURABLE_TRACE_PRINCIPLE.md) 和原 Work 合同负责。

## 9. 有界现场观察与 UI 到达/效果

先核对当前授权覆盖的站点、账户、操作与数据范围。源场景采用过人工启停、点击白名单、只读聚合输出和不遍历页面等限制；这些可按风险选用，不是所有任务的前置要求。分页、导出或其它操作分别按本任务授权与实际副作用判断；观察结束后，核对并按需要恢复本任务改变的现场。

UI 没有反应时，把两件事分开：

- **动作是否到达目标**：检查浮层、禁用状态、焦点与命中位置；当前工具支持时，可用命中测试确认覆盖关系。
- **预期效果是否出现**：核对查询条件、计数、页签、渲染或已验证有效的请求观测；界面未变也可能是结果相同、异步等待或本地处理。

“发出了点击”不等于点击到达；“没看到请求”不等于平台拒绝响应。即使确认动作到达，也先报告本次观察到的效果与范围，不凭单次无变化断言没有接口。

## 10. 报告只覆盖证据支持的范围

- **读入内存与持久化分开**：确实既未保存原始行、也未保存账户值时，才可写 `NO_ROWS_OR_ACCOUNT_VALUES_PERSISTED`；只证明其中一项时，按实际已证范围报告，不能扩大结论或改写成“从未接触响应内容”。保存过哪些层，按实际报告。
- **原始与派生分开**：结构表、摘要或解析后的对象不等于原始响应体，更不等于 wire bytes。需要字节级证据时，在 §5 的授权边界内保存原件、校验值与来源信息；只取得派生结构时如实标明。
- **同口径再比较**：页签计数、时间窗计数、导出行数可能对应不同总体。先核对时间列、时区、端点、状态、分页、统计单位与去重规则，再判断差异原因。
- **历史与当前分开**：标明来源版本/采集时间和覆盖范围；过去成功不能替代本次读取与当前性证据。
